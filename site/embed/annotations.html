反白文字，加上重點、筆記或圖片；不會改動 Markdown 原文。滑過標記就能查看補充內容，右上角可儲存。

在你的網站啟用

一般筆記只要設定 features: {annotations: true}，就有內建的重點、文字註解與拖入圖片註記。要接自己的選圖流程，再提供 selectionActions 與 onAction。

const editor = mountLumaReader(container, {
  document: savedSnapshot,
  features: { annotations: true },
  onSave: snapshot => saveToYourBackend(snapshot)
});
