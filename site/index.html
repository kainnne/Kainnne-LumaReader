WHAT IT SOLVES

Local Markdown reading and editing for individual developers.

Open project documentation and development notes from their existing folders. Read them in a clear layout or edit beside a live preview, with your files on your own computer.

  • Work from your project folders

    Open a Markdown file or choose a folder. Keep the existing structure, search file and folder names, and switch between documents in the sidebar.

  • A comfortable reading layout

    Read headings, tables, code, and diagrams as a formatted document. Adjust text size, reading mode, palette, and light or dark appearance to suit your screen.

  • Edit beside the result

    Keep Markdown source and its preview together. Text wraps to the editor width, and the preview follows your editing position.

  • Keep control of your documents

    Reading and editing need no account or document upload. Creating a Web share link sends a temporary copy to the share service for 30 days; remote images may contact their hosts.

DETAILED FEATURES

LumaReader feature details

Supported formats, folder navigation, reading modes, rendering, editing, and interface settings are listed below.

  1. 01
    Supported Markdown and text formats
    • Markdown · on by default.md, .markdown, .mkd, .mdx
    • Plain text · opt in.txt, .log
    • Format filterEnable TXT and LOG separately when needed
  2. 02
    Folder library, search, and sidebar navigation

    Each desktop document shows its containing folder in the sidebar. Search file and folder names together to expand matching results, refresh the library, and check scanning or read-access notices when something is missing.

  3. 03
    Vertical, horizontal, and paged reading modes

    Use vertical, horizontal, or paged reading. Vertical text wraps to the available width; wide tables and code can scroll within their own blocks. Paged navigation supports left/right and up/down page turns.

  4. 04
    Extended Markdown rendering

    Render tables, task lists, alerts, highlighted code, KaTeX mathematics, Mermaid diagrams, footnotes, emoji, abbreviations, superscript, subscript, and reusable local includes.

  5. 05
    Create, edit, preview, and save Markdown

    Choose any destination folder for a new .md, then write beside a live preview. Insert common Markdown structures from the editor menu or drop in an image; LumaReader keeps your editing position stable and asks before discarding unsaved changes.

  6. 06
    Export the rendered document as PDF

    Enable Export PDF in Settings. The desktop app exports an A4 PDF with code, tables, diagrams, mathematics, and images. Before saving, set a footer name or leave it blank; your choice is remembered. Put <!-- lumareader:pagebreak --> on its own line for a page break.

  7. 07
    Local documents and interface settings

    The Settings gear brings together 11 interface languages, light and dark modes, 22 palettes, and controls for hiding individual toolbar features. Preferences stay saved, and the first-launch guide shows where to adjust them.

  8. 08
    Open Markdown in the desktop app

    On macOS and Windows, choose LumaReader from Open With for .md, .markdown, .mkd, and .mdx. On Linux, run the AppImage and open a file or folder inside the app. Each file opens in an editable window, up to eight at a time. Default-app choices remain in your operating system settings.
