# Kainnne LumaReader 1.1.0

Version 1.1.0 makes Markdown editing more deliberate while keeping LumaReader focused on local reading and personal control.

## What changed

- Added an **Insert** menu for headings, emphasis, links, quotes, code, tasks, tables, and images.
- Images can be chosen or dropped into the editor. The desktop app copies them into a portable folder beside the Markdown document and inserts the relative syntax automatically.
- Kept the editor and preview at the same visible position when inserting Markdown structures.
- Added a confirmation dialog before unsaved edits are discarded.
- Combined light/dark appearance, all 22 palettes, language, and individual toolbar visibility under one larger **Settings** gear. Source and Media begin hidden, and the palette panel remains open while comparing styles.
- Updated the first-launch guide to introduce Settings as a core part of the interface.
- Refined PDF page spacing, softened the page frame, and placed a lower-opacity `Kainnne LumaReader` mark near the outer lower-right corner of every page.
- Added system file associations for `.md`, `.markdown`, `.mkd`, and `.mdx`. LumaReader now appears in **Open With** and can be chosen as the default Markdown app.
- Replaced the product icon throughout the app, website, Web Reader, and browser-extension assets.
- Brought the same Settings, Insert, image, and unsaved-edit behavior to LumaReader Web while preserving its three-document, no-folder-library, and no-PDF boundaries.
- Added a privacy-minimal combined macOS + Windows download counter. Counting starts with v1.1.0 and stores only platform totals.

## Distribution notes

The macOS Universal build supports Apple silicon and Intel Macs. It is signed with Developer ID, notarized by Apple, and validated by Gatekeeper in the release workflow.

The Windows x64 Setup and Portable builds remain unsigned. Windows may therefore show Microsoft Defender SmartScreen or **Unknown publisher** warnings even when the files are downloaded from the official release.

LumaReader remains free, open source, and local-first. Download only from [lumareader.kainnne.com](https://lumareader.kainnne.com/) or the official [GitHub Release](https://github.com/kainnne/Kainnne-LumaReader/releases/tag/v1.1.0).
