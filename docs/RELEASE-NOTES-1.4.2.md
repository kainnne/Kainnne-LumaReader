# Kainnne LumaReader 1.4.2

## 繁體中文

- 反白文字後可加入重點、文字備註或圖片註記。註記另外儲存，不會把符號或圖片寫進 Markdown 原文；圖片可拖入，滑過註記時預覽。
- 閱讀模式也能加入註記並自動儲存。半透明工具列可切換至下方中央或右下角，並記住位置；儲存失敗時保留註記並提供重試。
- 匯出 PDF 可選擇是否帶入畫好的重點，並在儲存前查看實際預覽。
- 桌面主選單新增 Settings，顯示項目、配色、深淺色與語言和右側設定同步。預設保留編輯、閱讀方式與設定齒輪；隱藏齒輪後仍可由主選單或 Cmd/Ctrl+, 開啟設定。
- Edit／編輯改為置中的純文字，維持原本字級。原文切換鈕顯示「顯示原文」或「返回直接編輯」；對照預覽移到儲存左側，切換與儲存狀態變化時不再推動其他按鈕。
- Web 與嵌入版同步純文字編輯按鈕和註記工具列改善，既有嵌入指令與資料接口維持相容。

註記保存在 App 的本機資料中，單獨複製 Markdown 不會帶走註記。嵌入網站須透過既有註記快照及附件接口自行保存資料；不會自動接上網站後台。

## English

- Add highlights, comments, and image annotations to selected text without rewriting the Markdown document. Drop an image onto an image annotation and hover its mark to preview it.
- Reading-mode annotations save separately and automatically. A translucent toolbar can dock at the bottom center or bottom right. Failed saves retain the notes and offer a retry.
- Optionally include highlights in exported PDFs and review the actual PDF before saving.
- A native Settings menu mirrors the desktop panel. Edit, reading mode, and Settings appear by default; Cmd/Ctrl+, remains available when the gear is hidden.
- Edit is a centered text label at its original size. Source editing uses Show source / Visual editor labels, with comparison preview to the left of Save and stable action positions.
- Web and embedded readers receive the text-only Edit treatment and annotation toolbar refinements, preserving existing installation commands and integration contracts.

Desktop annotations are stored in app-local data and do not travel with a copied Markdown file. Embedded hosts must persist annotation snapshots and attachments through the existing APIs.

## Downloads

- macOS: Universal Apple silicon / Intel build, signed, notarized, and stapled; standard pink icon.
- Windows: x64 Setup and Portable, unsigned. Windows may show a SmartScreen warning.
- Linux: x64 AppImage and .deb, validated on Ubuntu 22.04 and 24.04.

The app does not automatically change the operating system's default Markdown handler.
