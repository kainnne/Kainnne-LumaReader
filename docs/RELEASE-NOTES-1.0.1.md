# Kainnne LumaReader 1.0.1

Version 1.0.1 is a focused editing update for the local-first Markdown reader on macOS and Windows.

## What changed

- **Reach the true preview bottom when needed.** Normal synchronized scrolling stays unchanged. When the source reaches the end but the rendered preview still has content below, a **Show bottom** button appears inside the preview.
- **Clear feedback while editing.** Selecting another Markdown file during editing now shows a palette-matched notice that reminds you to save or exit editing first.

## Downloads

- **macOS:** Universal DMG and ZIP for Apple silicon and Intel Macs. The application is signed with Developer ID and notarized by Apple.
- **Windows:** x64 Setup and Portable executables. These builds are unsigned, so Windows may show Microsoft Defender SmartScreen or unknown-publisher warnings.

LumaReader remains free, open source, and local-first. Download only from [lumareader.kainnne.com](https://lumareader.kainnne.com/) or the official [GitHub Release](https://github.com/kainnne/Kainnne-LumaReader/releases/tag/v1.0.1).
