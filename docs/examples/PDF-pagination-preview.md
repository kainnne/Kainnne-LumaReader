# PDF 分頁微調測試

這份文件用來試試新的「微調分頁」。請先退出編輯模式，再按 ⌘⇧E 匯出 PDF。

## 先測試指定換頁

這是第一段。開啟 PDF 預覽後，在左側「微調分頁」選下面的「第二段」，把方式設成「從本段換頁」。右側預覽應該把第二段移到新的一頁。

第二段：我希望這段從新的一頁開始。再改回「自動」，這一段就會接回前面的內容，不會改動 Markdown 原檔。

## 原本指定的新頁

在微調分頁裡，選取「原本指定的新頁」，改為「接續前段・減少留白」。在紙張還有空間時，這個標題和內容就會接到前面，不需要把上頁剩餘空間整塊留白。

## 表格與完整段落

| 項目 | 狀態 | 說明 |
| --- | --- | --- |
| 第一段 | 測試中 | 可指定從新頁開始 |
| 換頁標記 | 測試中 | 可在本次匯出暫時取消 |
| 短表格 | 測試中 | 可選「本段盡量同頁」 |
| 長表格 | 測試中 | 超出整頁時仍必須分頁 |

## 確認原檔沒變

可以同時調整多個區塊；前方有圓點的項目就是這次已調整的區塊。按「重設分頁調整」應回到原來排版。試著儲存 PDF，再次開啟匯出視窗，這次的臨時微調會清除。

彩色外框、灰色頁尾名稱與其位置維持前一版本。可依需要勾選外框、調整字級與留白，右側預覽更新完再儲存。
