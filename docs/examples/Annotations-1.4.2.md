# LumaReader 1.4.2 註記測試

閱讀時直接反白下面任一段文字，就會出現「重點、註解、圖片註記」。也可先按「編輯」，一邊改稿一邊註記。

選單右側的小箭頭可切換下方中央與右下角，位置會記住。選單背景半透明，文字和按鈕維持清楚。

## 畫重點

今天想記住的這句話，值得再讀一次。

反白上一句並按「重點」。閱讀時註記會自動另存；編輯時則按右上角儲存。Markdown 不會多出標籤。

## 留一則筆記

午後的陽光落在窗邊，桌上的茶還冒著熱氣。

反白上一句並選「註解」，寫下補充。點選標記可以查看、修改或刪除筆記。

## 用圖片補充

這一段適合搭配一張風景照片。

反白上一句並選「圖片註記」，拖入 PNG、JPG、GIF 或 WebP。儲存後，結束編輯；滑過標記就會顯示圖片。

## 檢查重新開啟與 PDF

儲存後重新開啟這份文件，確認標記與圖片仍在。結束編輯，再匯出 PDF，切換「包含重點標記」，比較兩種預覽。

PDF 會顯示文字上的重點標記，不會印出滑過時的浮動圖片或筆記視窗。

## 試試復原

反白這句話，新增註記後按 Command + Z，再按 Command + Shift + Z。

註記會隨同復原與重做。若在原文模式或其他程式修改 Markdown，無法確認的註記會保留在設定的「待確認的註記」，不會猜測它應該移到哪一句。
